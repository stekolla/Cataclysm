# Browser saves

Cataclysm stores saves and settings in the browser's storage for the current site and browser
profile. Clearing site data can remove them.

Use **Save and Quit** (`S`) before reloading or closing the page. If the game reports that it could
not write to browser storage, try saving again before reloading.

Open the game on HTTPS or localhost and use one Cataclysm tab per site. If another tab is open,
close it and reload the page to access your saves.

If a save fails to load or behaves incorrectly, report the problem using the
[bug report form](https://github.com/stekolla/Cataclysm-BN/issues/new).
