# Potential future changes

These are ideas for discussion, not planned work.

## Per-world seeds for world generation

Give each world its own seed instead of using the game-wide random number generator for world
generation. Let players enter a seed when creating a world or leave it blank to generate one
automatically. Save the seed with the world and use it when generating new areas after a reload.

With the same game version, mods, and world settings, the goal is for the same seed to produce the
same terrain regardless of unrelated random events in the game session.
